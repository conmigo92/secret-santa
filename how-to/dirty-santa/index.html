How to play

Dirty Santa. Pass one phone around and roll.

What you need

Two or more people, one wrapped gift each, and one phone.

Setup

Enter names in seat order. Left is the next name, and the last person's left is the first name. The timer starts at 3 minutes. The game starts with 1 round. The host can set the timer, choose 1 or 2 rounds, and set each die face. Reset faces puts the die back to the list below.

The die starts like this.

  • 1. Pass your gift left
  • 2. Pass your gift right
  • 3. Swap with anyone
  • 4. Everyone passes left
  • 5. Everyone passes right
  • 6. Keep and roll again

A turn

Roll, then do what that face says. The turn moves left. With the starting die, a 6 means the same person rolls again, and a 3 means pick someone else. You can't pick yourself.

How it ends

You can pause the timer. When it hits zero, everyone keeps the gift in front of them. If the host chose 2 rounds, the gifts unwrap first. Name them if you want, then roll again for the same time.

Tips

  • Call the gift by its number until someone names it.
  • The game stays in this browser until someone starts a new one.
