How to play

Secret Santa. You buy for one person, and only you see that name.

What you need

Two or more people, and a way to send each person a link. Nobody needs an account.

Setup

The host adds every name, then marks pairs who must not draw each other, such as a couple. An exclusion goes both ways. A budget and an exchange note are optional. The host types them on the setup screen, and they show on every link.

A turn

The host draws names. Open the private link with your name on it. It shows the person you buy for, and the budget and the note if the host added them. It doesn't show anyone else's match.

How it ends

Buy that gift and bring it to the exchange. This page doesn't track what you bought.

Tips

  • Send each person only their own link.
  • Drawing again makes new links. A link you already sent still shows the old match.
